Multi-Agent trip planning

Send a flight request to the shared Multi-Agent Server through this feature's backend API. A Planner creates the plan, a Worker produces a recommendation from flight records retrieved from the flight database, and a Reviewer checks that result against the evidence. The workflow then pauses for human review.
