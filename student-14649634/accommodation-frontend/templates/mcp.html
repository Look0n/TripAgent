Accommodation Tools

MCP mode is available with tools below:

get_accommodations

Retrieve all accommodation records.

get_accommodation_by_city

Retrieve accommodation records for a specified city.

search_accommodations

Search by city, maximum price, guests and type.

check_accommodation_availability

Check availability for an accommodation over a date range.

list_tripagent_services

List TripAgent feature services.

get_service_status

Check the health of a TripAgent feature service.

list_available_tools

List tools available to a TripAgent feature.

get_tripagent_help

Return help about TripAgent, MCP or RAG.

get_system_summary

Return non-sensitive TripAgent architecture information.
